### roadnet2更新geom的SRID格式

**建议直接在数据库中永久修复 SRID：**

请在数据库客户端执行以下两条 SQL：

1. **更新数据，将所有 SRID 为 0 的数据设为 4326：**

   ```sql
   UPDATE china_roadnet2 
   SET geom = ST_SetSRID(geom, 4326) 
   WHERE ST_SRID(geom) = 0;
   ```

2. **告诉 PostGIS 这个列现在的 SRID 是 4326（更新元数据）：**

   ```sql
   SELECT UpdateGeometrySRID('china_roadnet2', 'geom', 4326);
   ```



### 启动命令

celery启动命令（进入虚拟环境，根目录输入）

```bash
celery -A scattering worker --pool=threads -l info
```

django启动命令（进入虚拟环境，根目录输入）

```bash
python manage.py runserver 0.0.0.0:8888
```
